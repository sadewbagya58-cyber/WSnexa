# WSNexa Report Export Center Guide

## 1. Supported Export Formats

1. **CSV (Comma-Separated Values)**:
   RFC 4180 compliant raw data export with formula injection protection.
2. **Excel (.xls / XLSX Table)**:
   Spreadsheet XML formatted workbook with styled headers and currency totals.
3. **Print / PDF Executive Summary**:
   Print-optimized HTML executive summary for immediate PDF generation via browser `window.print()`.

## 2. Export Datasets
- Executive Sales Summary
- Payment Method Breakdown
- Menu Items Performance
