# WSNexa Staff Invitation Operational Guide

## Managing Staff Invitations (For Business Owners)

### 1. Generating a New Invitation
1. Log in to WSNexa Dashboard as a Business Owner.
2. Navigate to **Business ➔ Staff Invitations** (`/dashboard/team/invites`).
3. Click **Generate New Invitation**.
4. Select the target **Branch** and **Assigned Role** (`Branch Manager`, `Cashier`, `Kitchen Staff`, `Waiter`).
5. (Optional) Enter an **Invited Email** to restrict claiming to a specific email address.
6. Choose expiry duration (`24 Hours`, `48 Hours`, or `7 Days`).
7. Click **Generate Code**.
8. **Copy Code / Copy Full Invite Text** from the one-time display modal. Send it to your manager or staff member via secure communication.

---

### 2. Revoking an Invitation
- Under **Staff Invitations**, find any pending invitation.
- Click **Revoke**. The code will be invalidated immediately.

---

### 3. Regenerating an Invitation Code
- If a staff member loses their invitation code, click **Regenerate**.
- The previous token will be invalidated immediately, and a new code will be generated and displayed once.
